# Client Project Management Platform

A responsive client/project management website based on the supplied internship task screenshots.

## Included
- Dashboard
- Project Management
- Task Management
- Milestone Tracking
- Time Tracking
- Client Management
- File Sharing UI
- Team Management
- Project Reports
- Profile
- Login
- Logout
- Create New Account
- Local browser data storage using localStorage
- Responsive layout for desktop/tablet/mobile

## Run in VS Code
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `login.html` in a browser, or use the VS Code Live Server extension.
4. Demo login:
   - Email: `admin@clientpm.com`
   - Password: `admin123`

## Important
This version is a frontend/demo implementation. Login and data are stored in the browser with localStorage. For real production authentication, connect the forms to a backend/API and database.
